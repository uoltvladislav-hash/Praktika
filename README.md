Веб-приложение для мгновенной конвертации валют по актуальным курсам Центрального банка РФ.

 🚀 Возможности

- 🔄 Конвертация между 8 валютами: RUB, USD, EUR, GBP, CNY, JPY, KZT, TRY
- 🏦 Автоматическая загрузка курсов с API ЦБ РФ при запуске
- 📋 История последних 10 конвертаций (сохраняется в SQLite)
- 🌙 Тёмная и светлая тема (выбор сохраняется в браузере)
- 📱 Адаптивный дизайн для мобильных устройств
- ℹ️ Модальное окно с информацией о проекте

 🛠 Технологии

- **Python 3.12** — язык программирования
- **FastAPI** — веб-фреймворк
- **SQLite** — база данных
- **Jinja2** — шаблонизатор HTML
- **HTML + CSS** — пользовательский интерфейс
- **API ЦБ РФ** — источник курсов валют

🔧 Установка и запуск

1) Установить зависимости
 pip install -r requirements.txt

2) Запустить сервер
python main.py

3) Открыть в браузере
http://127.0.0.1:8000

📡 API Центрального банка РФ
Курсы валют загружаются с открытого API ЦБ РФ при каждом запуске сервера:
https://www.cbr.ru/scripts/XML_daily.asp
Если API недоступен, приложение использует резервные курсы из базы данных.
